# Minesweeper
A simple ASCII game written in C++, that can be played inside the terminal.

### About
This project began as a request from a friend, while the main purpose of the project is to advance in learning game logic, and advancing on vectors.

### Features
* Randomly generated mines
* Different difficulties [Easy, Medium and Hard]
* Movement through the Board Grid
* Flag Placement and Removal
* Recursive Zero-Cell Revealing
* Colored Numbers
